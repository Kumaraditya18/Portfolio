## 🚀 Key Performance & UX Enhancements

This project has been redesigned to achieve optimal load speeds, visual clarity, and fluid user flows:

1. **Lightweight 3D Graphics**: Replaced a heavy 23MB GLTF 3D model with a custom, procedurally generated double-layered Three.js particle system (0 bytes downloaded, runs at 60 FPS, reacts dynamically to user cursor coordinates).
2. **Scroll Hijack Elimination**: Replaced annoying GSAP scroll-pinning on the Experience and Projects sections with native scrolling and smooth viewport fade-ins via Framer Motion.
3. **Structured Information Architecture**: Categorized technical expertise (Frontend, Backend, AI/ML, Utilities) and restructured projects with clear "Problem-Solution" engineering summaries.
4. **Tailwind CSS v4 & React 19**: Utilizes CSS variables and theme configurations inside CSS modules (`src/index.css`) along with React 19 hook optimization.
5. **SEO Optimization**: Configured custom title headers, indexing tags, search descriptions, and semantic HTML structures.
